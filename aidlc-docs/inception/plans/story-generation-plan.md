# PlanRepo MVP 사용자 스토리 생성 계획

## 목적

승인된 최소 요구사항을 사용자 중심의 작고 검증 가능한 스토리와 페르소나로 변환한다. 구현 세부사항이나 MVP 제외 기능은 추가하지 않는다.

## 선택된 생성 방식

- **페르소나**: 로컬에서 문서를 검토하고 결정하는 단일 통합 페르소나
- **분해 방식**: 핵심 흐름 순서에 따른 사용자 여정 기반
- **세분화**: 성공 경로 중심의 핵심 스토리 5개 내외
- **인수 조건**: 간결한 체크리스트 형식

## 스토리 분해 선택지

### 사용자 여정 기반

저장소 연결부터 Markdown 내보내기까지 사용 순서에 따라 스토리를 구성한다. 핵심 경로 스모크 테스트와 직접 연결하기 쉽고 이번 MVP에 가장 간결하다.

### 기능 기반

GitHub 연결, 문서, 파서, 의사결정 저장과 같은 기능 단위로 구성한다. 기능 경계는 명확하지만 사용자의 전체 성공 흐름이 분산될 수 있다.

### 페르소나 기반

문서 작성자와 검토자의 목표에 따라 스토리를 나눈다. 다중 사용자와 권한이 제외된 이번 MVP에서는 중복이 생길 수 있다.

### 도메인 기반

문서 관리와 의사결정 관리 도메인으로 구분한다. 향후 확장에는 유리하지만 현재 범위에는 구조적 부담이 있다.

### 에픽 기반

상위 에픽 아래에 세부 스토리를 둔다. 큰 로드맵에는 적합하지만 1.5일 MVP에는 계층이 과도할 수 있다.
