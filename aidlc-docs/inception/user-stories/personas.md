# PlanRepo MVP 페르소나

## P-01 로컬 문서 검토자

### 개요

AI-DLC 또는 Spec-Driven Development를 사용하는 개발자로서, 공개 GitHub 저장소의 명세 문서를 빠르게 읽고 미결정 질문을 정리해야 한다. 이번 MVP에서는 문서 작성자와 검토자의 역할을 하나의 로컬 사용자로 통합한다.

### 목표

- 여러 Markdown 문서에서 아직 답하지 않은 질문을 빠르게 찾는다.
- 질문의 원문과 선택지를 함께 보고 결정을 내린다.
- 여러 답변을 한 번에 확정하고 다음 작업 세션에서도 유지한다.
- 답변이 반영된 Markdown을 내려받아 후속 개발 과정에 사용한다.

### 동기

- 문서마다 흩어진 의사결정 사항을 수작업으로 찾는 시간을 줄이고 싶다.
- 합의 결과를 일관된 AI-DLC 답변 형식으로 남기고 싶다.
- 원격 저장소를 변경하지 않고 안전하게 결과를 검토하고 싶다.

### 주요 작업

- 공개 GitHub 저장소와 명세 폴더를 연결한다.
- Markdown 문서를 탐색하고 내용을 읽는다.
- 미결정 질문 대기열을 검토한다.
- 선택지를 고르고 답변을 일괄 확정한다.
- 답변이 반영된 Markdown을 내려받는다.

### 제약

- 로컬에서 실행되는 단일 사용자 환경만 사용한다.
- 공개 GitHub 저장소만 조회할 수 있다.
- GitHub 로그인, 비공개 저장소, GHE 및 원격 쓰기는 사용할 수 없다.
- 댓글, 그룹 승인, 실시간 협업 및 LLM 기능은 사용할 수 없다.

### 사용자 스토리 매핑

- **US-01**: 공개 저장소와 문서 폴더 연결
- **US-02**: Markdown 문서 탐색 및 안전한 열람
- **US-03**: 미결정 질문 대기열 확인
- **US-04**: 답변 선택, 일괄 확정 및 유지
- **US-05**: 답변이 반영된 Markdown 내보내기
