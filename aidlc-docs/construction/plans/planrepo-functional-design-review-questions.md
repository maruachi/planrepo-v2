## Question 1

기능 설계 산출물을 검토한 결과를 선택해 주세요.

A) Continue to Next Stage — 설계를 승인하고 NFR Requirements로 진행

B) Request Changes — 수정할 내용을 아래 답변 뒤에 기재

[Answer]:A

Functional Design 단계의 표준 2옵션 규칙을 따른다. 수정·기타 의견은 B에 설명을 덧붙인다. 기존 정책을 다시 묻는 것이 아니라 새 산출물의 검토 승인이다.
